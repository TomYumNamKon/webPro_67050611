# Weather Dashboard

## การทำงาน

เริ่มต้นการทำงานโดย ผู้ใช้พิมชื่อเมืองเข้าไปและ enter และ js จะทำการไปขอข้อมูลผ่าน api โดยจะดึงข้อมูล api ที่ตอนแรกเป็น HTML เราก็จะทำการดึงมันมาสร้างเป็น obj ของแต่ละตัวแปลที่เราต้องการ เช่นอุณหภูมิ โดยจะดึงเก็บข้อมูลมาเป็น array ของ 5 วันด้วย โดยหลังจากนั้นก็ใช้คำสั่ง js ไปเพิ่มตัวข้อมูลต่างๆตามข้อมูล api

## หมายเหตุ

โปรเจกต์นี้เปลี่ยนมาใช้ API ของ WeatherAPI.com แทน OpenWeatherMap ที่อาจารย์ให้มา เนื่องจาก API Key ของ OpenWeatherMap สมัครแล้วต้องใช้เวลารอสักพักถึงจะเปิดใช้งานได้ จึงเปลี่ยนมาใช้ WeatherAPI เพื่อให้สามารถเรียกข้อมูลจริงมาทดสอบและใช้งานได้ทันที
